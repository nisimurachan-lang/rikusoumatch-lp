# 背景: アドネス代表インタビューより（要約）

出典: YouTubeインタビュー動画（冒頭〜約5分）の自動文字起こしを要約。聞き間違いを含む可能性があるため、固有名詞・数値は目安として扱う。

## ジャイアントキリング
- 大手が100人かけてやっていることを、3人ほどのチームがAIで実現できる時代。
- アドネスは「会社の脳みそ」のような存在を目指している。

## 事業構造
1. **スクール事業（スキルプラス）**: 個人事業主・副業したい会社員・主婦・転職希望者・小さな会社の経営者向けのビジネススキル教育。
2. **AIプラットフォーム事業**

## 「内製化 → マニュアル → 商品化」の型
- 社員約120人で、システム開発・SNS運用・広告制作・テレビCM・撮影編集・広告運用・対面営業・AI活用まで**すべて内製**。
- マネージャーが部下に教える過程で**マニュアルが自然にできる**。
- そのマニュアルを一般向けに書き直し、**行動計画まで付けてパッケージ化**したものがスクール。
- つまり「自社でできること＝教えられること＝売れること」。

## 学習体験の設計
- オンライン学習が基本。加えて**毎週、無料の集中合宿**（1〜2日、朝から夜まで）。
- テーマは「1日で動画編集ができるようになる」「1日でAIが使えるようになる」のように**短期間で成果が出る単位**に切る。
- 講師は社内スタッフ。AIで既存ノウハウがすぐ上書きされるため、**コンテンツは常に最新に更新**する。

## AI動画編集（Claude Code）
- Claude Code を使った動画編集の仕組みを社内で運用。有名YouTuberの動画制作にも使用。
- フィラー（「えー」「あのー」）のカット、Vlog風編集などを含め、**人の作業は数秒、ほぼワンショットで完成**。
- 素材の長さ（数時間）にかかわらず対応。

## このスキルへの示唆
- 自動化した業務は、そのまま**人に教えられるマニュアル**、さらに**商品**になる前提で書く。
- 学習・作業の単位は「1日で成果が出る」粒度に分割する。
- ノウハウは陳腐化する前提で、改善履歴を残し定期的に更新する。
- 動画編集のような重い制作業務も「素材を投げる→ほぼ完成品が返る」ワンショット化を目標にする。
